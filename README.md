# SAIN education

Course material.

For the recovered evaluations notebook, see [Colab in VS Code](COLAB_IN_VSCODE.md).

## Getting started

1. Fork this repo: click **Fork** at the top of this page.
2. Clone your fork and link it to this repo:

```
git clone git@github.com:<your-username>/education.git
cd education
git remote add upstream git@github.com:SAIN-Utrecht/education.git
```

## Getting new material

```
git pull upstream main
```

## Saving your work

Commit and push to your fork as usual:

```
git push
```
